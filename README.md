# My D&D
An independent fan-made Dungeons & Dragons web companion.

## Run locally
```bash
npm install
npm run dev
```
Build with `npm run build`.

## First foundation
- Responsive digital character sheet
- Overview, ability scores, skills, combat, spells, inventory, features and notes
- Editable ability scores, hit points, inventory and notes
- Dice roller and recent roll log
- Spell-slot, resource and condition tracking
- Browser local storage and JSON export

## Planned
Character builder, rules compendium, monster and item databases, campaigns, encounters, combat tracker, homebrew, DM tools, party inventory and optional multiplayer.

Independent fan project; not affiliated with Wizards of the Coast or D&D Beyond. Use only content you have rights to use.
